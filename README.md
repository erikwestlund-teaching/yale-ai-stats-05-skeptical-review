# Module 7: AI as a Skeptical Reviewer

Part of the workshop **AI-Powered Coding and Data Analysis**. The prompt is on the course page.

This project contains a finished analysis in `notebooks/analysis.qmd`. You'll ask an AI tool to review it.

## Install packages

Run this once in the R console, from the project folder:

```r
source("setup.R")
```

It installs any missing packages used anywhere in the workshop: readr, dplyr, tidyr, ggplot2, broom, here, and rmarkdown. If you already ran it for another workshop project, you can skip this step.

## Open the project

- **RStudio:** open `yale-ai-stats-05-skeptical-review.Rproj`.
- **Positron or VS Code:** open this folder.
- **Claude Code or Codex:** start the tool from a terminal in this folder.

You need R and Quarto. Quarto comes with RStudio and Positron.
